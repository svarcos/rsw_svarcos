# RSW svarcOS — Расчёт параметров и построение циклограммы точечной сварки

*Для технологов-сварщиков*

[![Flutter](https://img.shields.io/badge/Flutter-3.10.6-blue)](https://flutter.dev) [![Dart](https://img.shields.io/badge/Dart-3.0.0-blue)](https://dart.dev) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**RSW svarcOS** — мобильное и веб-приложение для расчёта параметров точечной сварки и визуализации циклограммы. Предназначено для инженеров-сварщиков, технологов и специалистов по контактной сварке.

Приложение рассчитывает режимы точечной сварки для алюминиевого сплава АМг6 и визуализирует сварочный цикл на трёхфазной сварочной машине постоянного тока Tecna ING-1324 на основе параметров блока управления Tecna TE550.

## 🎯 Что умеет приложение

- **Ввод исходных данных**: материал, толщина деталей, рабочий ход электродов.  
- **Автоматический расчёт параметров** по таблицам и формулам:  
  - `POWER` — мощность / ток сварки  
  - `WELD` — время сварки  
  - `PRESSURE` — давление / усилие сжатия  
  - `POST-POWER`, `POST-WELD` — параметры операции после сварки  
  - `HOLD TIME` — время удержания  
  - `SQUEEZE 1` — время сжатия электродов  
  - `FORGE DELAY` — задержка включения ковки  
  - `FORG.PRESS.` — усилие ковки  
  - `COLD 3` — пауза между сваркой и послесварочным импульсом  
- **Построение циклограммы** с двумя осями:  
  - Ток (синяя линия, % от мощности)  
  - Давление (красная линия, бар)  
- **Интерактивная корректировка** параметров с мгновенным обновлением графика  
- **Русская локализация** интерфейса и обозначений

## ⚙️ Основные функции
### Вкладка «Параметры»
* Исходные данные: выбор материала (АМг6, Сталь 20, Сталь 12Х18Н10Т), толщина деталей, расстояние между электродами

* Расчёт: кнопка «Рассчитать» пересчитывает все параметры

* Ручная корректировка: изменение ползунком или вводом числа

* Автообновление: диаметр точки пересчитывается при изменении толщины

### Вкладка «Циклограмма»
* График тока и давления в зависимости от времени

* Левая ось: ток (0–100%)

* Правая ось: давление (0–6 бар)

* Всплывающие подсказки при наведении

* Информация о количестве импульсов

### Расчётный модуль
* Табличные данные для АМг6 (0,3–3,0 мм)

* Интерполяция для промежуточных толщин

* Основные формулы:

```text
PRESSURE = S1 (наименьшая толщина)
SQUEEZE 1 = d / 2,5 + PRESSURE / 0,3 + 6
FORGE DELAY = WELD – (FORG.PRESS. – PRESSURE) / 0.3
FORG.PRESS. = 2 × PRESSURE (≤ 6,0)
COLD 3 = 3,5 (константа)
POST-WELD = 0,8 × WELD
POST-POWER = 0,45 × POWER
```
